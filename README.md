# 쉬운예약 — 고령층 친화 대화형 병원 예약 웹앱

스마트폰 조작과 작은 글씨가 어려운 65세 이상 어르신이 다른 사람의 도움 없이 **당일 병원 진료 예약을 3분 안에** 끝낼 수 있도록 만든 연습용 웹앱입니다.

- 배포 주소: **https://easy-booking-coral.vercel.app**
- 기획 문서: [`PRD.md`](PRD.md)
- 개발 과정 프롬프트 기록: [`docs/PROMPTS.md`](docs/PROMPTS.md)

> 이 앱은 수업 과제용 **연습 앱**입니다. 실제 병원에 예약되지 않으며, 모든 병원·의사·환자 정보는 가상 데이터입니다.

## 이런 문제를 풀었습니다

| 기존 예약 앱에서 겪은 일 | 쉬운예약에서는 |
|---|---|
| 비밀번호·의사 이름을 기억해야 해서 멈춤 | 지난번 병원, 가장 빨리 볼 수 있는 선생님을 먼저 제안하고 고르기만 함 |
| 달력에서 날짜를 잘못 누르고 모른 채 진행 | 달력 없이 오늘 예약 가능한 시간만 큰 버튼으로, 고른 내용을 문장으로 되읽어 줌 |
| 마감(회색) 시간을 반복해서 누름 | 마감된 시간은 아예 보여 주지 않음 |
| 뒤로 가기 한 번에 입력이 사라져 포기 | 고를 때마다 바로 저장, 뒤로 가도·새로고침해도·앱을 닫아도 이어서 할 수 있음 |

## 주요 기능

- **한 화면에 질문 하나**: 큰 글씨(본문 20px·질문 28px 이상), 화면 폭 전체의 큰 버튼(높이 64px 이상), 명도 대비 7:1 이상
- **예약 흐름**: 시작 → 병원 확인 → 선생님 확인 → 시간 선택 → 되읽기 확인 → 본인 확인 → 방문 이유 → 최종 확인 → 예약 완료
- **되읽기 확인**: "오늘, 11월 11일 수요일 오후 2시 30분, 샘물내과의원으로 예약할까요?" — [다시 고를게요]로 병원·선생님·시간 중 하나만 바꿀 수 있음
- **큰 숫자 키패드 본인 확인**: 기기 키보드 없이 화면 키패드로 생년월일 6자리, 누른 숫자를 가리지 않고 되읽어 확인, 틀려도 횟수 제한 없음
- **실수 복구**: "← 이전으로"와 브라우저 뒤로 가기가 똑같이 바로 앞 질문으로, 고른 것은 그대로 / 예약 도중 나가려 하면 확인 / 다시 열면 "하시던 예약이 있어요. 이어서 할까요?"
- **소리로 듣기**: 켜면 화면이 바뀔 때마다 질문을 한국어로 읽어 줌 (지원하지 않는 브라우저에서는 버튼이 보이지 않음)
- **글씨 크기**: 보통 / 크게 / 아주 크게, 설정은 저장됨
- **내 예약**: 예약 확인과 취소
- **저녁 예외 처리**: 오후 5시 30분 이후에 접속하면 "오늘 진료는 끝났어요. 내일 가장 빠른 시간으로 예약할까요?"로 바뀌고 모든 문구가 "내일"과 내일 날짜로 나옴

## 실행 방법

[Node.js](https://nodejs.org/) 20.19 이상(또는 22.12 이상)이 필요합니다.

```bash
npm install
npm run dev        # 개발 서버 (터미널에 나오는 주소로 접속)
npm run build      # 배포용 빌드 (dist/)
npm run preview    # 빌드 결과 미리 보기
```

휴대폰 화면처럼 보려면 브라우저 개발자 도구의 기기 모드에서 너비를 360px 정도로 맞춰 보세요. 데스크톱에서는 가운데 480px 너비로 표시됩니다.

### 시험용: 현재 시각 바꾸기

주소 끝에 `?now=시:분`을 붙여 접속하면 그 시각인 것처럼 동작합니다. 같은 탭에서는 계속 유지되고, `?now=reset`으로 되돌립니다.

- `/?now=17:40` → 오후 5시 30분 이후: 내일 예약으로 바뀌는지 확인
- `/?now=10:05` → 오전: 예약 가능한 시간이 많아 "다른 시간 더 보기" 확인

## 가상 데이터 안내

| 종류 | 내용 |
|---|---|
| 예약하는 분 | 김영희 (가상 인물) |
| 연습용 생년월일 | **500101** (본인 확인 화면 아래에도 안내됨) |
| 병원 | 샘물내과의원(내과, 샘물동), 한빛가정의학과의원(가정의학과, 한빛동), 푸른정형외과의원(정형외과, 푸른동) — 모두 가상의 이름 |
| 의사 | 병원마다 2명, 실제 사진 대신 이름 첫 글자 그림 |
| 예약 시간 | 접속한 시각 이후 오전 9시~오후 5시 30분 사이 30분 단위로 만들고, 의사마다 일부 시간을 마감 처리 |

- 실제 개인정보(주민등록번호, 환자번호, 질병명)를 입력받지 않습니다.
- 서버와 데이터베이스가 없습니다. 진행 중인 예약, 완료된 예약, 글씨 크기·소리 설정은 **이 브라우저의 localStorage에만** 저장됩니다. 브라우저 사이트 데이터를 지우면 함께 지워집니다.

## 기술 스택

React 19 · TypeScript · Vite · Tailwind CSS 4 · React Router · Web Speech API(SpeechSynthesis) · Vercel

```
src/
  components/   공통 화면 틀(ScreenLayout), 큰 버튼, 키패드, 진행 안내 등
  pages/        화면들
  state/        예약 상태(자동 저장·이어서 하기), 설정(글씨 크기·소리)
  lib/          날짜·시간 규칙, 예약 가능 시간 만들기, 음성, 저장소
  data/         가상 데이터
  styles/       디자인 토큰 (색·글씨·크기 규칙을 한 곳에서)
```
