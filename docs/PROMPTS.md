## 4

- 날짜: 2026-11-11
- 프롬프트:

  > 3단계로 넘어가자

- 결과: 10장 3단계(자동 보존, 뒤로 가기 처리, 이어서 하기, 나가기 확인)를 진행했다.
  - 자동 보존(FR-24): 고르거나 숫자를 누를 때마다 화면을 다시 그리기 전에 바로 localStorage에 저장한다. 마지막으로 보던 화면 주소도 저장한다. 예약을 마치면 진행 내용을 지운다.
  - 이어서 하기(FR-03, FR-26): 앱을 다시 열면 시작 화면 대신 "하시던 예약이 있어요. 이어서 할까요?"와 지금까지 고른 내용 요약(예: 샘물내과의원, 박지훈 선생님, 오전 10시 30분까지 고르셨어요.)을 보여 준다. 중간 화면에서 새로고침하면 그 주소 그대로 같은 질문을 보여 주고, [이어서 할게요]를 누르면 같은 화면으로 돌아온다.
  - 이어서 한 뒤에도 "이전으로"와 브라우저 뒤로 가기가 바로 앞 질문으로 가도록, 시작 화면에서 이어서 할 때 흐름 순서대로 기록을 다시 쌓는다. 새로고침 뒤 [처음부터 할게요]를 누르면 지난 흐름의 기록을 되감아 뒤로 가기가 지난 화면들을 거치지 않게 했다.
  - 나가기 확인(FR-27): 예약 도중 이전으로·뒤로 가기로 시작 화면에 오면 "하시던 예약이 있어요. 정말 나가시겠어요?"와 [계속 예약할게요]/[나갈게요]를 보여 준다. 나가도 진행 내용은 남는다.
  - 브라우저 자동 검수로 시나리오 3(3자리 → 뒤로 가기 → 돌아오면 3자리, 새로고침 뒤에도 유지), 시나리오 4(본인 확인 단계에서 새로고침 → "하시던 예약이 있어요" → 같은 단계), 다시 열기, 나가기 확인, 처음부터 하기, 새 화면의 4.2 수치 규칙을 확인해 모두 통과했다. 2단계 검수도 다시 돌려 통과했다.

  - 글씨 크기(FR-31): 버튼을 누르면 바로 아래에 [보통]/[크게]/[아주 크게]가 열리고, 고르면 바로 바뀌며 저장된다.
